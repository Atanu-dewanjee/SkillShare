# SkillSphere Mobile App (`apps/mobile`)

The **Flutter** mobile app used by students. It is built Android-first and kept iOS-ready.

> **Status:** Placeholder. The Flutter project will be generated here in a later stage. This README will then be replaced with setup and run instructions.

## Responsibilities

- Registration, login, and profile management.
- Discover, search, and filter skills and mentors.
- Publish skill offers.
- Send, accept, decline, and negotiate learning requests.
- Set availability and book sessions.
- Private real-time chat.
- View credit balance and ledger history.
- Leave reviews and report users or content.
- Receive push notifications.

The app talks only to the SkillSphere REST API and Socket.IO server (`apps/api`).
