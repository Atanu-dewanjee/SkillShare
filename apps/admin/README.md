# SkillSphere Admin Portal (`apps/admin`)

A **Next.js** web application for SkillSphere administrators and moderators.

> **Status:** Placeholder. The Next.js project will be generated here in a later stage. This README will then be replaced with setup and run instructions.

## Responsibilities

- Manage user accounts.
- Review reports submitted by users.
- Hide inappropriate content.
- Restrict accounts when necessary.
- Monitor basic platform activity.

The admin portal has no database access of its own. It talks only to the SkillSphere REST API (`apps/api`), which enforces all permissions.
